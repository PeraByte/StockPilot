# StockPilot

Video Demo: https://youtu.be/IDi8ckCkehw

Description:

StockPilot: is a web application that helps a small shop keep track of what it has, what it sells and what it earns. A business owner registers, adds products, sells them through a built-in point of sale, and sees live figures on a dashboard. It is built with Python, Flask, SQLite, Jinja2 templates and plain JavaScript, so it runs on a laptop with no external services.
